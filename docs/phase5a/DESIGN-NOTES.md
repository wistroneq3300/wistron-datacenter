# Phase 5A HQ 設計決策

日期：2026-11-13。本輪交付是行善路 158 號的 **Draft 建築視覺模型**，供使用者檢視。設計採用已辨識同址的官方歷史全景與公開入口近景；它不是實測 BIM、現況認證或精準建築還原證明。

## 最終方向

- **先修正可見的量體。** 官方 2012 照片支持 4 個上部玻璃帶、2 個石材基座節奏、階梯左翼、中央凸弧玻璃帶、延伸右翼及末端玻璃量體。這些特徵構成辨識度；程式內的高度、半徑與窗寬仍為比例估算。
- **以幾何建立立面深度。** 連續牆面具有實際窗洞、退縮玻璃、窗框與窗下陰影，入口位於中央弧形玻璃帶下方。雨棚區分玻璃、深色放射肋架與後段面板。窗後暗面僅表現深度，未建立虛構的實際房間。
- **石材有不同的用途與表面。** 最後一輪將立面調整為可見灰色顆粒與分縫；入口品牌碑使用獨立粗石顆粒，取消貼面板狀分縫；深色雨棚肋架與玻璃保持可辨差異。這是根據照片的材料判讀，並無石材產品、色卡或粗糙度量測。
- **光照服務建築閱讀。** 日間保留石材與藍綠玻璃層次，黃昏呈現冷暖差，夜間使用局部入口／路燈。HDRI 提供通用環境反射，程序天空作背景；沒有將國外全景宣稱為台北現場。玻璃物理材質、SSAO、陰影與曝光均為展示設定。
- **植栽維持可控成本。** 彎曲漸細枝條、葉片 atlas、alpha 陰影及逐樹 LOD 提供自然細節。樹冠仍較稀疏、部分形態重複；種植位置、樹種及場地空白維持 Draft，沒有為填滿畫面而新增未經佐證的周邊建物或屋頂設備。

[`VISUAL-REVIEW.md`](VISUAL-REVIEW.md) 已接受最後一次材質／雨棚修正，建議以 Draft 提交使用者審閱；不再啟動一般性的重建或反覆修飾。該判斷保留樹冠、空白周邊與簡化屋頂的限制，也不等同完整遊戲環境品質認證。模式按鈕過渡是否已穩定、導覽及效能是否通過，以主測試的最終證據為準。

## 凍結範圍與整合邊界

P1–P4 的 Cinematic Rack、設備配置與驗證、八層 Navigation State、Digital Twin 狀態資料及既有產品 UI 為保留基礎。本輪 HQ 有自己的視角、光照與展示控制，以及必要的入口交接／行動版 HQ 控制排列；沒有以環境升級為由重設 Rack、Hall、Telemetry 的產品行為或整體介面。

HQ 沿用原 renderer、RAF 與 CameraDirector；後製只在 HQ 層使用，離開後由既有內部環境接手。相機展示可取消，入口交接回原導覽。上述為設計與實作邊界，功能是否完全保留仍須由 Regression 證明。資源成本與釋放方式見 [`CODE-REVIEW.md`](CODE-REVIEW.md)。
